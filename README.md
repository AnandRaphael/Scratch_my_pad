# Scratch Pad ✏️

A playful paper-desk canvas for dumping thoughts, sketching, and explaining ideas on screen shares.
No install, no build, no backend: just open it in a browser.

## Run it
- Locally: double-click `index.html` (or run `open index.html` on a Mac).
- Online: via GitHub Pages (see below).

## Use it
| Action | How |
| --- | --- |
| Sticky note | `N`, then click. Or double-click anywhere |
| Free text | `T`, then click |
| Pen / Eraser | `P` / `E`, then drag |
| Select / move | `V`. Drag items, drag the orange dot to resize |
| Edit text | Double-click an item. `Esc` to finish |
| Recolor | Select an item, click a color dot |
| Delete | Select, then `Delete` / `Backspace` |
| Pan | Drag the empty desk, hold `Space` and drag, or scroll |
| Zoom | `Cmd/Ctrl` + scroll or pinch. Click the % badge to reset |
| Undo / Redo | `Cmd/Ctrl+Z` / `Shift+Cmd/Ctrl+Z` |
| Companion | Click **🧸 Buddy** or press `B` to summon a little bear. Press `B` again (or `Esc` when nothing is selected) to send it away |

Boards autosave in your browser. Use **💾 Save** / **📂 Open** to move boards between browsers, and **🖼️ PNG** to share an image.

## Deploy (GitHub Pages)
Push to GitHub, then Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
